## Machinery added (all internal; no sim.js export, decide kind or event wording changed)
- **trackLife / lifeLostNow (77).** `g.life` is an enumerable getter/setter installed by `trackLife(g)` (in `newGame` and at `beginTurn0`); every drop adds to `_lostN`/`_lostSeq`, which are NON-enumerable (a restored game, `Decide.dump`, remember.js never see them; the first version had them enumerable and broke the snapshot tests). `lifeLostNow(g)` is per turn sequence (`(g.match||g).seq`, every player's turn counts). `condMet` 'noLifeLost' (a goldfish's opponent turn: `g._soloOppTurn`), dyn kind 'selfLost'. Also 'oppEnd' triggers (`a.oppEndTrig`): a goldfish at the start of its own turn in `ghostTurn`, match/pod in `endTurn0`.
- **_yardOut / perm.fromYard (82).** `trackYard(g)` wraps `g.graveyard.splice` (non-enumerable own method; installed in `newGame` and `beginTurn0`) and marks each removed card with `{seq, act}` (non-enumerable). `enterWithTriggers` sets `perm.fromYard` when the card left in the same `g.actSeq`; `perm.castYard` for fbCast/escaping/retracing/breaching (a cast is not "entered from"). permEtb triggers: `fromYard`, `orCast`. **Gotcha: a test that does `g.graveyard = []` replaces the wrapped array; use `g.graveyard.length = 0`.** `castFilterOk` `fromYardCast` (River Kelpie). `payDo` effect, `attackAny` `tokenAtk`, effect `neyali` (exiled cards with `neyali === true` come back to hand with `temp` on a later token attack; cleanup resets 'hand' to true).
- **rollDice (79).** The one place a d20 is rolled (d20 effect, Delina, Gold Dragon, Ancient Copper Dragon's chain; same rnd() calls, note text 'Rolled a d20: N' unchanged). `a.rollPlus` (stacking "roll that many dice plus one, ignore the lowest"), 'rolled' triggers once per roll (`a.rollTrig`, n token ROLL), `a.tapRoll` (Vexing Puzzlebox rolls as it taps for mana), d20 `rows` result tables (Component Pouch, Treasure Chest; the table lines are claimed with their roll line; effect `chestTutor`). Classes are read stage by stage (`stagedCard`), so a Class line works from its level.
- **Finality counter (81).** `leavePerm0`: a permanent with `other.finality > 0` that would die is exiled (next to Rest in Peace). `yardBack` `finality`; effects `returnDead` (Meathook II), `putTribe` (Kastral, read by `parseEffects`), `sacThreeReturn` (Scavenger's Talent).
- **milledEvent / libYardEvent / rad (76).** `milledEvent(owner, cards, ev)` fires 'milled' triggers (`a.milledTrig`; what nonland/creature/any, whose, perTurn, each) after a mill, a real opponent's mill and a rad mill; `libYardEvent` fires 'libToYard' (`a.libYardTrig`) for mill, surveil and rad. ## Gotchas found in this session
- A new `case` name can collide with an existing one and silently shadow it (my 'doubleCounters' shadowed Mossborn Hydra's): `grep -n "case 'name'"` first; the fingerprint's game lines catch it.
- Anything new on the game object or on a card/permanent that is enumerable shows up in `Decide.dump` and remember.js; use `Object.defineProperty(..., { enumerable: false })` (as trackLife, trackYard) or make sure a restored game ends up identical (tests `decisions` and `remember-snapshot` fail otherwise).
- `parseEffects` can claim a line before your rule: put a card's rule in the newest block of the parser (before "rules batch 7x") so it wins, and check `tools/engine/cov.js` shows the trigger in `trig [...]`, not just 'ok'.
- `Object.assign({}, g, ...)` (cloneState) flattens getters: the clone has a plain `life` and no tracking; dry runs ignore it.
- Class cards are staged: the base reading has only level 1 lines; a test must level up through `G.abilityMenu` / `G.useAbility`, not set `p.level`.
- `leavePerm0`'s `dest == null` means "to the graveyard"; set `dest = 'exile'` there for replacement effects. `castCard(g, inst, true)` skips costs; `resolveSpellInner` is reached for permanent spells too, but the instant/sorcery block sits in the `else` after `if (a.isPermanent)`.
- The suite writes `/tmp/suite.log` etc. only because I ran it that way; a stale `exit` line from an older run fools a monitor: delete the log before a new run.
- Checks per batch: fingerprint before/after (`node tools/engine/finger.js out.json`, `--diff`), `node tests/run.js` (about 9 minutes now), `node tools/every-default-sweep.js` (bad 0), `NODE_USE_ENV_PROXY=1 node tools/fetch-sets.js --report` then `node tests/run.js sets`.
