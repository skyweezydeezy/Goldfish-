# Promotion tracker

Live site: <https://skyweezydeezy.github.io/ICEYfish/>

## Assets
- `goldfish-qr.png` – QR code, 1000px+, for print/social
- `goldfish-qr.svg` – QR code, vector (scales for posters/flyers)
- `goldfish-qr-logo.png` – branded QR with the ice-cube fish logo (error correction H, navy on white)
- `flyer/flyer.png` (300 dpi, US Letter) and `flyer/flyer.svg`: one-page flyer around the logo QR, seven tabs, Scryfall and Wizards Fan Content credit. Source: `flyer/make-flyer.js` (run `node docs/promo/flyer/make-flyer.js` from the repo root).
- `posts.md`: draft Reddit (r/EDH) and Discord posts. Not posted; read each place's rules first.

All three encode the site URL above (plain codes: error correction Q; logo code: H, mask 0). Regenerated 2026-11-23 for the ICEYfish address; each was decoded with two OpenCV QR decoders at full size, 300 px and 160 px. If the address changes (e.g. custom domain), regenerate them; printed codes would then need replacing, so consider a custom domain before printing.
