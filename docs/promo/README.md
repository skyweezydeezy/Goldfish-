# Promotion tracker

Live site: <https://skyweezydeezy.github.io/Goldfish-/>

## Assets
- `goldfish-qr.png` – QR code, 1000px+, for print/social
- `goldfish-qr.svg` – QR code, vector (scales for posters/flyers)
- `goldfish-qr-logo.png` – branded QR with the ice-cube fish logo (error correction H, navy on white)

Both encode the site URL above with error correction level Q. If the address changes (e.g. custom domain), regenerate them; printed codes would then need replacing, so consider a custom domain before printing.
