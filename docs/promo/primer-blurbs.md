# Primer blurbs: Moxfield and Archidekt

Drop one of these at the end of a deck primer or description. Link: https://skyweezydeezy.github.io/Goldfish-/
Both sites render Markdown links; the QR code (`goldfish-qr.png`) can be uploaded as an image where images are allowed (e.g. a Moxfield primer/Imgur link), but a plain link is safer.

Rules of thumb: say it's free and needs no sign-up, make it about the deck (not an ad), and don't repost the same text across many decks in a row.
